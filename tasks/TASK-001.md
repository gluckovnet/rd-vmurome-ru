## Что сделать

Заменить мок-заглушки в `public/index.html` на реальную работу с API.

### 1. Заменить мок-submit на fetch к CRM API

Сейчас в обработчике `submitBtn` — `setTimeout` на 1500 мс (строка ~460).
Заменить на `fetch()` к бэкенду CRM.

### 2. Убрать хардкод WordPress category ID

Сейчас в `<select id="category-select">` жёстко прописаны ID категорий WordPress
(73, 90, 179, 180, 931, 181, 182). Эти ID принадлежат WordPress-сайту rd.vmurome.ru,
которого больше нет. Заменить на строковые ключи (`utility`, `utilities`, `legal`,
`social`, `medical`, `infrastructure`, `unverified`) и передавать их в API как строки.

### 3. Убрать или переделать СМС-модалку

Сейчас СМС-поток полностью замокан (нет реальной отправки, код любой).
Если CRM API поддерживает верификацию телефона — подключить.
Если нет — убрать СМС-модалку, заменить на простую отправку телефона вместе с формой.

### 4. Исправить ссылку в thank-you

Сейчас `thankLink.innerHTML` содержит хардкод `https://rd.vmurome.ru/t/mock-123`.
Заменить на реальный URL из ответа API (если API его возвращает) или убрать блок.

## Что я ожидаю увидеть

- `rd.vmurome.ru` отдаёт чистый HTML (без wp-json, без RSS-фидов, без wp-content)
