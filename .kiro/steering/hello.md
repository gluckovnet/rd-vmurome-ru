## Что за проект

Статический PWA — одна HTML-визитка с формой обратной связи:
- Форма: описание проблемы + фото/видео + email + телефон
- Два режима: анонимный и с регистрацией (СМС-подтверждение)
- Отправка в CRM API (бэкенд)
- Домен: https://rd.vmurome.ru/

## Как работать

```bash
# Локальный сервер (из public/)
python3 -m http.server 8080
# → http://localhost:8080/
```

Правишь `public/index.html` → обновляешь браузер → видишь сразу.

## Как деплоить

SSH-алиас `prod` уже настроен (www-vmurome@172.22.14.66).

```bash
# Создать директорию на проде (один раз):
ssh prod 'mkdir -p www/rd.vmurome.ru'

# Каждый деплой:
rsync -avz public/ prod:www/rd.vmurome.ru/

# Проверить:
curl -sI https://rd.vmurome.ru/ | head -3
```

## Порядок действий сейчас

1. Прочитай `PLAN.md` — пойми где мы
2. Прочитай активную задачу в `tasks/` (TASK-001.md)
3. Делай → тестируй локально → деплой → клади `.done.md`
4. Жди приёмки главврача

## Важно

- **НЕ пиши .done.md пока не проверил на проде.** ACCEPT в задаче — твой критерий готовности.
- **Заметил что-то вне задачи → запиши в `OBSERVATIONS.md`** (если нет — создай).
- **Застрял → пиши в `tasks/HELP-NNN.md`** (главврач увидит).
- **Деплоишь ТОЛЬКО index.html и статику.** Никаких WordPress, PHP, БД.
